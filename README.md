# Afzal Hussain — Portfolio

This repository contains the source for my personal portfolio website. I use it to introduce my work, share selected projects, describe the areas I’m learning and working in, and provide a way to get in touch.

The site is built as a static page using HTML, CSS, and a small amount of JavaScript.

## What’s on the site

- Introduction and current areas of interest.
- Selected project summaries with links to repositories where available.
- Skills and tools grouped by area.
- Education and background.
- Contact links and a form that prepares a message in the visitor’s email application.

## Implementation

The current page is implemented in `index.html`. The layout, styles, and page behaviour are included in that file; the repository does not currently use a frontend framework or a package-based build process.

## Run locally

Clone the repository:

```bash
git clone https://github.com/Afzu01/Afzu01.github.io.git
cd Afzu01.github.io
```

Open `index.html` in a browser.

## Development notes

The contact form uses the visitor’s mail application to prepare an email; it does not submit messages to a backend service. Project descriptions on the portfolio page should be kept in sync with the actual state of their linked repositories.
